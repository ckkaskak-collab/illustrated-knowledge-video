# 角色绑定与当前彩色角色组

用于持续制作同一组角色的 A-roll，或用户要求三视图、固定人物形象时。三视图提供造型参考，不能保证模型自动维持身份；每张成图仍须对照检查。

角色在 A-roll 中如何选角、搭戏和承接知识讲解，读取 [三人组场景设计](aroll-cast-design.md)。本文件只维护外观与参考用法。

## 生图时怎样使用

1. 在项目记录中写明角色 ID、所选版本、参考文件路径，以及本镜出场角色。相同项目沿用同一版本，不因新图更精致便自行替换。
2. 实际查看并传入本镜角色的三视图作为身份参考；需要时同时传入已认可的阵容图说明具体角色。提示词明确哪张负责身份，哪张负责场景与动作，不能只写“参考以上图片”。彩色组覆盖旧黑白角色的颜色、服装、五官限制；仍保持 A-roll 完整图片定帧规则。
3. 同一场景先确定一张通过检查的基准图，后续每张继续传入角色参考及该基准图。上一张图只补充动作状态，不替代原始身份参考，避免逐张累积变形。
4. 提示词分开写“固定身份”和“本张变化”。每张只画本次需要的姿态与场景，不把三视图的三个人、标签或排列方式带进成片。
5. 需要反应表情时，先参考已通过的场景表情。反复使用的困惑、惊讶、无奈、得意等可按实际需求补成表情参考，不必在开始前批量生成所有表情。嘴形是图片中的静态表情，不制作自动口型动画。

## 检查重点

- 对照发束与刘海方向、脸型、头身比例、领口、袖长、裤腿和鞋型；小猫另外核对额头斑块、胡须和尾巴数量。避免用整图镜像获得另一侧视图而改变不对称身份特征。
- 女生的发夹固定在人物自身左侧，被遮挡时不移到另一侧；背面保留帽子，不画正面袋鼠兜。男生侧面眼镜腿连接耳部，背面不画眼镜或正面口袋，侧分发型不随意反向。
- 表情变化后仍认得出同一人物，不因惊讶就变成另一套大眼睛或写实五官。
- 同框的角色配色与比例一致，道具和手部数量连续。局部失误优先局部编辑该图，保留合格部分。
- 记录本次实际发现的偏差与修正；不能把“传入了三视图”写成身份一致性已通过。
