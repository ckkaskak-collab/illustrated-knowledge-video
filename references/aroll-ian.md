# A-roll 角色与动作接口

这是本工作流的角色制作接口，不是 X 或飞书提示词原文。Ian 风格参考已内置于 `illustration/`，不需要安装另一份 Skill。未指定角色时以 [包内原图](../assets/character/reference.jpg) 为准；项目已有角色时，以该项目参考和身份说明覆盖默认角色。延续彩色四人组，或需要三视图绑定时读取 [角色绑定](character-binding.md)，其中包含四个角色的包内参考图和身份检查规则。

## 传入上下文

先按[叙事与动作设计](visual-storytelling.md#a-roll把动作状态组织成一段小戏)确定本镜承担的铺垫、代入、情绪或衔接作用。把定稿全文作为背景，并为当前 A-roll 提供：

- 分镜整行，包括镜头号、时间、配音、画面设计、动态变化、衔接；
- 本镜要表达的意思、人物处境与意图、具体行动、物件，以及阻力/反应或结果状态；
- 多人镜头按 [三人组场景设计](aroll-cast-design.md)说明出场角色 ID、各人意图、当前主动行动者和反应对象；在既有状态表记录站位、视线与物件归属，不默认所有角色同时出场；
- 已有的前后镜头、视觉选择与本次实际请求的输出数量；
- 本镜动作状态表：状态编号、对应定稿短语及唯一短语 ID、手与道具发生的变化、需要锁定的机位/景别/位置、状态图路径；有实际音频时同时填写全片毫秒、镜头内相对毫秒和共享帧边界。

已有分镜时，按本次选中的 A-roll 镜头生成，不把 Ian 的文章默认 4–8 张直接当作视频镜头总数。镜头时长来自已给时间轴，Ian 只负责所需图像与配图方案，不重新估算时间或修改配音文案。

## 图像生成

1. 每张新图读取 [角色说明](illustration/character-ip.md)、[生图模板](illustration/prompt-template.md)；首次制作同时读取 [风格](illustration/style-dna.md) 和 [构图](illustration/composition-patterns.md)。这些是本包文件，不从宿主查找同名 Skill。用于视频时，把文章插图模板改为“当前镜头的一张动作状态图”，只呈现这一状态；流程、系统结构和多处标注按本镜需要取舍，不把整段解释画进每张 A-roll。
2. 每张生图前查看并传入项目选定的角色原图或三视图；未另行指定时使用[默认角色原图](../assets/character/reference.jpg)。将参考图的绝对路径作为 `image_gen.referenced_image_paths`，分别标明身份参考与场景基准。只借用身份，动作和构图按当前镜头重新设计；三视图不作为多格画面上轨。后续状态持续保留身份参考，不只依赖上一张成图。
3. 未指定项目画风时保留 Ian 的白底、黑色手绘线稿、克制的红橙蓝批注与留白；项目已确认的角色与画风优先。线条小人参与核心动作；不使用其上游案例角色替代用户 IP。人物、搭档、环境、道具及必要的静态视觉符号尽量由 Codex 图像生成工具直接输出为一张完整构图，不在剪辑中用代码绘制角色或拼装 MG 场景。生图时预留字幕空间；字幕单独上轨。
4. 生成后执行 [图像 QA](illustration/qa-checklist.md)，保存到项目的 `assets/aroll/`。记录图片对应的镜头号，文件名可带 `S001` 等镜头前缀方便后续剪辑。只交方案时不声称已生成图片。

默认不同时注入 X 的 04/05，避免三类参考、虚化场景等原路线要求与 Ian 当前的白底风格互相覆盖。需要重回作者原路线时，依据用户明确选择单独调用，原文档案保持不变。

## 与 B-roll 的边界

A-roll 通过人物在场景中的行动演绎处境，B-roll 通过知识对象与关系的变化完成讲解。Ian 对真实 UI、正式图表、PPT 等限制约束它生成的 A-roll 图片，不直接扩展到 B-roll。知识关系图、真实截图与录屏仍可按 B-roll 需要准备。

## 已选动作方式：关键状态图切换

本工作流的 A-roll 采用完整生成图片逐张定帧展示：一张图片在所属区间内保持静止，到切点直接换下一张。表现力来自图片中的构图、人物动作与表情、角色关系，以及切图节奏和停留时长。每个新状态应提供新的处境、行动、反应或结果；张数由内容决定，不平均分配时长，不强凑三张，也不因时长阈值强加动画。

不添加 MG、元素入场、局部移动、分层视差、口型或眨眼动画、呼吸抖动、推拉摇移、缩放或淡入淡出转场。不自动使用图生视频或插帧补动作。确需改变景别时独立生成对应的近景或反应图并直接切换；同一连续动作中的空间关系保持清楚。只有用户另行明确改变展示方式时才启用动画方案。

剪辑仅负责图片顺序、静止停留、直接切换，以及独立字幕和音轨。画幅适配可做固定等比缩放或必要的静态裁切，不能随时间运动或遮掉关键动作。旁白字幕按原有规则换屏，不做逐字弹跳；角色接话可用另一张表情或动作定帧表达，不默认合成新台词或新增配音。

1. 先写“本镜目标 → 人物处境与意图 → 行动及必要反应 → 结果”，为每次变化绑定定稿短语。用手、身体和物件的实际变化组织小戏；状态数量由动作可读性决定。没有真实音频时只做动作方案和素材准备，不编造毫秒时间。
2. 首张图通过 Ian QA 后作为本镜基准。后续图继续传入用户原图和已通过的基准图，明确各图角色身份/场景/编辑目标的作用；锁定机位、景别、画面方向、角色比例与未变化道具，只改变当前动作。每张独立输出，不用一张多格漫画替代多张状态素材。
3. 手、姿态、视线和道具表达反应，保留项目选定角色的五官等身份特征（默认角色无明显嘴巴）。检查持笔手、物件数量和放置位置的前后连续性；需要跳过中间动作时，下一状态仍须易于理解。
4. 每张图作为独立时间轴素材放入本镜区间。首张建立处境，后续换图对应真实短语/词锚点，静止保持到下一次有效变化或镜头结束。结果与反应留出读懂的时间，切图不机械跟随每次字幕换屏。
5. 关键过程读不懂时，先修正构图、人物与道具关系，或补一张必要的中间状态图；节奏拥挤时精简状态或调整停留。不用动画弥补分镜问题。

时间交接采用[时间与项目交接](timing-and-handoff.md)。检查时既看各状态的身份与构图，也看换图前后帧及完整段落：观众能否看懂人物遇到什么、做了什么、结果怎样，物件和持物手是否连续，结果是否有足够停留。抽查同一图片区间的首、中、尾帧，排除独立字幕变化后，场景内容、位置、尺度和透明度应保持一致；编码后的轻微压缩差异不当作运动。素材生成成功不能代替展示节奏验收。
